# v5.30.3 Codex额度连接诊断

设置入口：侦探控制台 → 监控与预警 → Codex额度。

点击“测试连接并刷新额度”后，状态区依次显示本机授权/程序哈希检查、桌面版运行状态、官方账户与额度读取结果。结果包含五小时与周额度、最近核验时间，以及经过截短的本机账户指纹，帮助确认读取的是预期账户。

若显示“连接成功”但五小时额度为“100% · 待启动”，代表 app-server 已经返回官方数据，当前窗口仍被官方标记为尚待首个模型请求启动。只读取额度不会发送对话，也不会启动该周期。已经发过消息仍看到此状态时，先核对 Codex 桌面版所登录账户与本页 CODEX_HOME 是否一致，再运行一次连接测试。

“测试连接时，若 Codex桌面版未运行则自动启动”默认关闭。开启后只在手动运行连接测试时尝试从开始菜单快捷方式启动桌面版；也可以使用“启动 Codex 桌面版”按钮手动打开。若自动定位不到快捷方式，会提示用户手动启动。此选项不影响额度后台轮询，也不会替用户发送模型请求。
