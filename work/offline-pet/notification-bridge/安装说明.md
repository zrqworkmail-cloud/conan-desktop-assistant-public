# 可选系统通知组件

此组件已构建为 unsigned MSIX（未签名），尚未安装或授权。便携桌宠的其他功能无需安装它。

## 开发验证

1. 审核 package/AppxManifest.xml 和 NotificationBridge.cs 源码。包声明 runFullTrust 与 userNotificationListener。
2. 开发者可以在 Windows 开发人员模式下使用 PowerShell：`Add-AppxPackage -Register "完整路径\package\AppxManifest.xml"` 注册展开的开发包。开发模式、注册或信任证书都应由使用者明确决定；桌宠不会自动执行。
3. 从开始菜单启动“柯南通知桥接”，点击“请求Windows通知读取授权”。
4. 在桌宠“通知中心”勾选接收。首次连接建立基线，随后新产生的应用 Toast 才会转交；保持桥接窗口运行。
5. 撤销权限后立即停止读取；关闭桥接窗口停止接收。来源屏蔽、只显示标题、勿扰在桌宠通知中心设置。

正式分发前需要使用受信任的代码签名证书签署 MSIX；未签名包不能双击安装。此交付没有自动开启开发模式、安装证书或系统包，也没有替你同意通知读取权限。

## 数据与边界

配置、心跳与短暂的本地收件文件位于 `%USERPROFILE%\.conan-assistant\notifications`。默认不接收，默认只转发标题；已消费通知只保留在内存和现有本地通知列表中。无需互联网，不删除Windows原通知。

仅支持Windows应用Toast；不保证读取传统托盘气泡、所有系统弹窗或重放应用内原通知按钮。点击来源通过应用ID打开来源应用。

代码编译与MSIX打包不代表授权后读取已验收；在新机器上仍需实际安装、授权和Toast测试。本项目已于2026-10-16完成本机受控Toast到桌宠气泡验收；撤销授权后的端到端行为仍未单独测试。
